go2ads modern website package

Files included:
- index.html: redesigned homepage
- services.html: service details
- pricing.html: plans and feature comparison
- contact.html: contact details and existing Google enquiry form
- privacy.html: privacy policy
- style.css and script.js: shared responsive design and interactions
- assets/: original logo, founder photo, client logos and service graphics
- CNAME: go2ads.in
- sitemap.xml: existing page sitemap

Deployment:
1. Extract this ZIP file.
2. Upload the contents inside the go2ads.dms-main folder to the root of the GitHub Pages repository, replacing the old site files.
3. Keep the repository's GitHub Pages source/branch and custom domain configuration as currently configured.
4. After publishing, test all pages, WhatsApp/call links, the embedded Google Form, and analytics in the live domain.

Existing Google Analytics ID, Meta Pixel ID, phone, email, GSTIN, Google Form embed, client content, and pricing from the supplied website were retained. Review all business details and pricing before publishing.
